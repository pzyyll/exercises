# Exercises

Programming exercises and small projects, grouped by primary language and framework.
Projects that use more than one language stay together under their primary language.

## C and C++

- `cpp/ameisen/`, `cpp/bis/`, `cpp/netframz/`: server and networking projects.
- `cpp/binary_tree/`, `cpp/hash_map/`, `cpp/list/`, `cpp/rb_tree/`, `cpp/skiplist/`: data structures.
- `cpp/lib_tools/`, `cpp/linux_study/`, `cpp/mmap/`: tools and system programming exercises.
- `cpp/oj/`, `cpp/thinking/`: programming and algorithm exercises.
- `cpp/opengl/learn-opengl/`: OpenGL exercises.

## Python

- `python/py-examples/`: utility examples.
- `python/try-doing/`: experiments, including Python memory analysis.

## Shell

- `shell/shell-snippets/`: reusable shell functions.

Each project retains its own build instructions and dependencies.
